Wiki du Projet - Portail Web & Intranet

1. Description de l'architecture du projet

Le projet est scindé en deux grandes parties hébergées sur le même serveur web (Apache / PHP) :

  • Site Vitrine (WordPress) : Gère la présentation publique de l'entreprise (Accueil, Activités, Histoire, Qui sommes-nous). Il intègre deux modules spécifiques :
    • Un plugin pour gérer et afficher les témoignages clients via le shortcode [temoignages_clients].
    • Un module pour afficher de façon dynamique les partenaires de l'entreprise (les données proviennent de l'intranet).
  • Intranet (PHP / Bootstrap 5 / JSON) : Application développée de zéro sans base de données MySQL. Toutes les données sont stockées au format JSON ou CSV. L'intranet comprend :
    • Un système d'authentification et de gestion de session.
    • Une gestion des permissions basée sur les groupes (admin, direction, managers, salariés, perso).
    • Un gestionnaire de fichiers partagés (.txt et .csv).
    • Des annuaires interactifs (Employés, Partenaires, Clients) avec fonctionnalités d'ajout, modification et suppression.

2. Description et utilisation des fonctionnalités

  • Page d'information (infos.html) : La porte d'entrée globale contenant les liens vers l'intranet, la vitrine, ce wiki, le dépôt Git et le Trello.
  • Portail de connexion Intranet : Interface sécurisant l'accès aux données de l'entreprise. L'accès est conditionné à l'appartenance à au moins un groupe.
  • Gestion des utilisateurs : Interface d'administration permettant de créer, modifier ou supprimer des comptes et d'assigner des droits.
  • Annuaires (CRUD) : Les salariés peuvent consulter les annuaires. Les utilisateurs autorisés peuvent ajouter de nouveaux profils (Employés, Clients, Partenaires), les modifier ou les supprimer. L'annuaire client permet en plus de télécharger une fiche individuelle.
  • Gestionnaire de fichiers : Interface permettant de téléverser de nouveaux fichiers (txt/csv) ou de consulter les fichiers existants selon les droits du groupe auquel appartient l'utilisateur.
